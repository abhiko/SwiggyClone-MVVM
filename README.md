
## 🍔 SwiggyClone-MVVM (SwiftUI)

**SwiggyClone-MVVM** is a modern, Swiggy-inspired food delivery app clone built using **SwiftUI** and the **MVVM architecture pattern**.
The goal of this project is to demonstrate **clean code practices, scalable folder structure, and a testable iOS architecture** suitable for real-world applications.

Currently, the app contains **one functional tab/module**. Additional features and tabs will be added gradually as the project evolves.

---

## ✨ Features (Current)

* SwiftUI-based user interface
* MVVM architecture pattern
* Clean and modular folder structure
* Single working tab (more coming soon)
* Reusable UI components
* API-ready architecture
* Dummy API integration *(planned)*
* Unit testing support *(planned)*

---

## 🧱 Architecture Overview

This project follows the **MVVM (Model–View–ViewModel)** pattern:

* **Model** – Handles data and API responses
* **View** – SwiftUI screens
* **ViewModel** – Business logic and data binding
* **Service Layer** – API handling *(upcoming)*
* **Utilities** – Common helpers and extensions

The structure is designed to scale easily as new tabs and modules are added.
